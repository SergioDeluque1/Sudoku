# Sudoku

A C++ implementation of Sudoku developed during a **time-constrained coding competition**.

The project explores solving an **NP-complete problem** through multiple approaches, with a focus on algorithm design, problem-solving, and software design patterns.

## Overview

- **Language:** C++
- **Problem:** Sudoku
- **Focus:** Multiple solving approaches and design patterns
- **Context:** Built during a timed coding competition

## Goals

- Explore different approaches to solving Sudoku
- Experiment with algorithms for an NP-complete problem
- Apply software design patterns to structure the implementation
- Compare different approaches under time constraints

## Approaches

The project implements multiple approaches to solving Sudoku, providing an opportunity to compare different algorithmic strategies and their performance.

The code also makes use of **design patterns** to keep the different components modular and extensible.

## Why Sudoku?

Sudoku is a well-known **NP-complete constraint satisfaction problem**. While its rules are simple, finding a solution can require significant search, making it a useful problem for experimenting with algorithms, heuristics, and software architecture.

## Building

Compile the project using a C++ compiler supporting the required language standard.

```bash
g++ -std=c++17 -O2 -o sudoku <source-files>
```
